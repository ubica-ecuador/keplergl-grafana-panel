# Panel options

Every option the panel exposes, in the order the editor groups them. `Path` is the key in the panel
JSON, which is what you need for dashboards-as-code.

## Field mapping

| Option        | Path            | Default       | Notes                                                                                                                                                           |
| ------------- | --------------- | ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Field mapping | `fieldMappings` | autodetection | Per query, keyed by `refId`. Detected values appear as placeholders; set one to override, or **None** to switch the role off. See [Field roles](./field-roles). |

## Map

| Option                         | Path                  | Default     | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------------ | --------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Show side panel                | `showSidePanel`       | `true`      | kepler's layer and filter panel. Worth hiding on small tiles.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Follow dashboard theme         | `followGrafanaTheme`  | `true`      | Restyles kepler's chrome from the Grafana theme, and drives _Match theme_ on the base map. See [Theme](../guide/map/theme).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Time range sync                | `timeSync`            | `toMap`     | `toMap`, `bidirectional`, `variables`, `off`. See [Time range sync](../guide/dashboard/time-range-sync).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Time window variables          | `timeVariables`       | —           | **Only shown when `timeSync` is `variables`.** The two variables the slider's window is published to, as UTC ISO 8601. See [Time window variables](../guide/dashboard/time-window-variables).                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Update variables while playing | `publishWhilePlaying` | `false`     | **Only shown when `timeSync` is `variables`.** Writes the window during playback rather than only when it stops. Costs the animation frames.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Playhead variable              | `playheadVariable`    | —           | Writes the trip animation's current instant to a variable as UTC ISO 8601: once on load, during playback at the interval below, and where it stops. One way, independent of `timeSync`. A stat of the taxis on the road right then, on PostgreSQL: `SELECT count(*) FROM trips WHERE NULLIF('$playhead', '')::timestamptz BETWEEN trip_start AND trip_end` — the `NULLIF` counts nothing while the variable is empty, where a bare cast of `''` fails. On data sources that add the quotes themselves, such as DuckDB, write `$playhead` unquoted; see [Time window variables](../guide/dashboard/time-window-variables#consuming-it). Set it on one map only. |
| Minimum interval while playing | `publishIntervalMs`   | `1500`      | **Only shown when `publishWhilePlaying` is on, or `playheadVariable` is set.** Least time between two writes during playback, 250 ms and up. See [Time window variables](../guide/dashboard/time-window-variables).                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Sync time with other maps      | `peerTimeSync`        | `false`     | Shares the time filter and trip playhead with the other maps on the dashboard that have this on, in the browser. See [Peer time sync](../guide/dashboard/peer-time-sync).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Trip layer                     | `tripLayerMode`       | `table`     | `table` keeps one row per point and every column with it; `geojson` folds each trip into one row and keeps only the path. See [Trajectories](../guide/data/trajectories).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Flow line style                | `flowRenderMode`      | `straight`  | `straight`, `curved`, `animated-straight`. See [Origin–destination flows](../guide/data/flows).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Base map                       | `basemap`             | `auto`      | `auto` (OpenFreeMap Dark or Positron, following the theme), `openfreemap-positron`, `openfreemap-bright`, `openfreemap-liberty`, `openfreemap-dark`, `openfreemap-fiord`, `dark-matter`, `positron`, `voyager` (CARTO), `grafana-satellite`, `grafana-satellite-terrain`, `grafana-topographic-terrain`, `custom`. See [Base maps and relief](../guide/map/basemaps-and-relief).                                                                                                                                                                                                                                                                               |
| Style URL                      | `customBasemapUrl`    | —           | **Only shown when `basemap` is `custom`.** A MapLibre `style.json` served from your own network.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| CARTO API key                  | `cartoApiKey`         | —           | Only for the CARTO base maps (`dark-matter`, `positron`, `voyager`), which since 23 Sep 2026 watermark their tiles without one. Free at [carto.com/basemaps/apikey](https://carto.com/basemaps/apikey/); public by design, it travels in every tile URL. Dashboard variables are interpolated.                                                                                                                                                                                                                                                                                                                                                                 |
| Raster tile server             | `rasterServerUrl`     | —           | TiTiler-compatible server that turns a COG or a Zarr store into tiles, for queries returning a `raster_url` or `zarr_url` column. None by default: until one is set those queries draw nothing and the panel names them. It reads the imagery on the map's behalf, so it has to be able to reach it, and is handed every URL, signature included. Development Seed's public demo, `https://titiler.xyz` (the default before 1.3.0), reads public imagery only. A `.pmtiles` URL needs no server and ignores this. See [Rasters](../guide/data/rasters).                                                                                                        |
| Raster colour ramp             | `rasterColormap`      | —           | Colour ramp for rasters a query produces: `blues`, `greens`, `reds`, `viridis`, `magma`, `greys`, `rdylbu`, `spectral`. Empty leaves kepler's own `cfastie`, which is built for drone NDVI and is not monotonic — on a continuous field it reads as confetti. Applies to single-band rasters; a true-colour scene is drawn from its bands. See [Rasters](../guide/data/rasters#colour).                                                                                                                                                                                                                                                                        |
| Let the tile server paint      | `rasterPainted`       | `false`     | Ask the server for finished pictures (`.png`) instead of raw values. Needed for a **classified** raster — land cover, soils — whose colours are a fact of the data: the ramp above cannot express nine named classes, and the browser rescales the class numbers over the whole data-type range, landing every class on one colour. The server reads the palette the file carries instead. The layer then offers only opacity, as PMTiles does. Leave off for imagery. See [Rasters](../guide/data/rasters#painted).                                                                                                                                           |
| Raster bands                   | `rasterBands`         | true colour | Which bands of a scene to draw, for a query that also returns a `raster_item_url` pointing at its STAC item: true colour, `forestBurn`, `infrared`, `nbr`, `ndmi`, or a custom value. The composites are built by the tile server in one request; the indices are computed in the browser from two bands, each with a diverging ramp of its own. A dashboard variable is interpolated here, so a dropdown can drive it. See [Rasters](../guide/data/rasters#band-combinations).                                                                                                                                                                                |
| Zarr value range               | `zarrRescale`         | —           | Range a Zarr variable is stretched over, as `min,max` in the store's own units — `0,30` for mm/day of rain, `270,305` for kelvin. Empty stretches each tile over its own extremes, so neighbouring tiles disagree about what a colour means and the map reads as patchwork. The ramp above is shared. See [Zarr stores](../guide/data/zarr#the-colour-range-is-not-optional).                                                                                                                                                                                                                                                                                  |

::: tip Velocity fields and symbols are configured on the layer
There is no wind option here, and no symbol option either. A Streamlines layer's density, trail,
cycle and smoothing, a Vector field's symbol and spacing, and everything the Symbols layer draws
live in their own panels inside the map, beside their colour — see
[Velocity fields](../guide/data/velocity-fields) and [Symbols](../guide/data/symbols).
:::

## Cross-filtering

| Option                              | Path                  | Default | Notes                                                                                                                                                                                                                                                                                                                                 |
| ----------------------------------- | --------------------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Cross-filtering                     | `variableMappings`    | —       | A list. Each row binds a column or a click to a dashboard variable. See [Cross-filtering](../guide/dashboard/cross-filtering).                                                                                                                                                                                                        |
| Publish drawn area                  | `areaVariable`        | —       | Writes the drawn polygon or rectangle to a variable as WKT in EPSG:4326. One way. See [Publishing](../guide/dashboard/publishing).                                                                                                                                                                                                    |
| Click to set the area               | `clickArea`           | `false` | **Only shown when `areaVariable` is set.** A click on an entity sets the area to a square around it, as if drawn by hand: it shows on the map and deletes like a drawing.                                                                                                                                                             |
| Square side (m)                     | `clickAreaSizeMetres` | `6000`  | **Only shown when `clickArea` is on.** Side of that square in metres — the same area at every latitude.                                                                                                                                                                                                                               |
| Select from the popup               | `clickConfirm`        | `false` | **Only shown when a `click` mapping exists, or `clickArea` is on.** A click only opens kepler's popup; its **Select** button publishes and **Clear** empties. For a map whose selection reloads data or changes a tab. See [Cross-filtering](../guide/dashboard/cross-filtering#select-from-the-popup).                               |
| Highlight rows where                | `selectionField`      | —       | A column of the query: the rows where it is true (or 1) are ringed as selected, beside what the click mappings publish, without the selection travelling in the URL. See [A selection the query flags](../guide/dashboard/cross-filtering#a-selection-the-query-flags).                                                               |
| Dim the rest                        | `dimUnselected`       | `false` | **Only shown when `selectionField` is set or a `click` mapping exists.** While the selection marks something, every other row is covered by a veil of the base map's tone. See [Dim the rest](../guide/dashboard/cross-filtering#dim-the-rest).                                                                                       |
| Selection outline                   | `haloStyle`           | `auto`  | **Only shown when `selectionField` is set or a `click` mapping exists.** `auto`: amber while nothing is dimmed; under the veil of `dimUnselected`, a thin line round up to 50 shapes and none beyond. `amber`, `thin` (one line in the base map's contrast colour) and `none` fix one.                                                |
| Publish viewport (for other panels) | `viewportVariables`   | —       | Four variables for the bounding box edges. See [Publishing](../guide/dashboard/publishing).                                                                                                                                                                                                                                           |
| Mosaic selection                    | `mosaicSelection`     | —       | The name of a Mosaic Selection on the dashboard (Chaski app). The map's range, time and multi-select filters are clauses in it, sent while they move, and the other panels' clauses on the map's columns land on its filters. See [Linked to a Mosaic selection](../guide/dashboard/cross-filtering#linked-to-a-mosaic-selection).    |
| Mosaic location columns             | `mosaicColumns`       | —       | **Only shown when `mosaicSelection` is set.** `lng, lat`: the longitude and latitude columns of the Selection's data, for the two options below.                                                                                                                                                                                      |
| Filter by the drawn area            | `mosaicArea`          | `true`  | **Only shown when `mosaicColumns` is set.** The latest figure drawn on the map keeps, in the Mosaic panels, the rows inside it.                                                                                                                                                                                                       |
| Filter by the view                  | `mosaicViewport`      | `false` | **Only shown when `mosaicColumns` is set.** The view filters the Selection as a bounding box while you pan and zoom.                                                                                                                                                                                                                  |
| Fit to data when these change       | `fitOnVariables`      | —       | A list of variables. When one changes, the map frames its new rows as on load, at the zoom they need; a refresh or any other variable never moves it. For pickers that move the data elsewhere (a state, a route). See [Fit to data when a variable changes](../guide/dashboard/cross-filtering#fit-to-data-when-a-variable-changes). |

### The shape of a `variableMappings` entry

| Key          | Meaning                                                                          |
| ------------ | -------------------------------------------------------------------------------- |
| `field`      | the column the mapping is about; meaningless for `coordinate` and `center`       |
| `variable`   | the variable that receives the value — or the **latitude** for a coordinate pair |
| `variableTo` | the upper bound of a numeric range — or the **longitude** for a coordinate pair  |
| `source`     | `filter` (default), `click`, `coordinate`, `center`, `chart`                     |
| `zoom`       | for `center` only: the zoom to jump to. Absent, the map keeps its zoom           |

A mapping with both `variable` and `variableTo` and no `source` is a **range** mapping: the numeric
filter on `field` publishes its min and max as a pair.

## Map configuration

| Option               | Path          | Default | Notes                                                                                                                          |
| -------------------- | ------------- | ------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Map configuration    | `saveRequest` | —       | The **Save current map** button. It is a counter, not a boolean, so repeated saves register.                                   |
| Import configuration | `mapConfig`   | —       | The stored configuration itself, and the textarea for pasting one in. See [Map configuration](../guide/map/map-configuration). |

::: tip Why the save button is a counter
Grafana gives panel option editors no channel to the panel component, and the map state lives in the
panel's own Redux store. So the editor bumps a counter and the panel — which can see its store —
does the capture. The **Save map** button the map shows in the panel editor needs no counter: it is
part of the panel, and calls that same capture directly.
:::

## Options this panel ignores

Grafana's standard field options — unit, decimals, colour scheme, thresholds, value mappings, data
links — do not affect the map. Colour comes from kepler's layer configuration; see
[Colour palettes and scales](../guide/kepler/colour-palettes-and-scales).

Data links are worth a specific note: a data link _on another panel_ pointing at this one's variables
is the basis of the **Center** mapping, and that works well. Data links configured on this panel do
nothing.
